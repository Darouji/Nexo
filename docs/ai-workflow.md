# Metodología de desarrollo asistido por IA

La IA se utiliza como apoyo dentro de un proceso controlado, con revisión humana.

1. **Comprender:** levantar necesidades, procesos, restricciones y casos de uso.
2. **Organizar:** convertir notas en requerimientos, decisiones y un documento de referencia.
3. **Investigar:** consultar documentación oficial y contrastar alternativas; usar Deep Research cuando el alcance lo justifica.
4. **Dividir:** trabajar por módulo y mantener el contexto acotado y actualizado.
5. **Implementar y revisar:** usar ChatGPT Work y Codex como apoyo; examinar los cambios y sus efectos en otros módulos.
6. **Validar:** ejecutar pruebas, lint, compilación y comprobaciones de datos antes de integrar.

No se presentan sugerencias de IA como resultados probados. No se atribuye una certificación de seguridad ni experiencia profesional senior por el uso de estas herramientas. Nunca se deben introducir datos de clientes o credenciales en documentación pública.
